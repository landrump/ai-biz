## Interpretation rules

### No impressions

Likely problem: keyword targeting, listing count, marketplace indexing, or
channel reach.

Next actions:

- Rewrite titles around buyer-search language.
- Add more long-tail tags.
- Publish more pin variants.
- Add one additional product/listing variation.
- Do not judge the product yet.

### Impressions but low clicks

Likely problem: thumbnail, title, first image, or buyer promise.

Next actions:

- Rewrite the first 40 characters of the title.
- Make the thumbnail promise more concrete.
- Test a more urgent use case, such as buyer agreement conversations.
- Compare individual product click-through against bundle click-through.

### Clicks but no favorites or carts

Likely problem: listing page trust, preview quality, perceived usefulness, or
price.

Next actions:

- Add clearer preview images.
- Show one before/after workflow example.
- Add a "what you can do in 30 minutes" section.
- Test a temporary launch price.

### Favorites or carts but no sales

Likely problem: price, hesitation, unclear deliverables, or low urgency.

Next actions:

- Add a first-week launch coupon.
- Improve FAQs and "what is included" sections.
- Bundle individual products with a stronger savings frame.
- Add Gumroad direct checkout as an alternate path.

### Sales but weak average order value

Likely problem: bundle framing or product ladder.

Next actions:

- Strengthen bundle positioning.
- Add "best value" messaging.
- Create a pro version waitlist or setup sprint interest link.

## Decision checkpoint

At the end of the first week, record:

- Best-performing product.
- Best-performing title.
- Best-performing thumbnail.
- Best-performing channel.
- Total spend.
- Total revenue.
- Conversion bottleneck.
- One next test.

## Week-two default actions

If there is any meaningful traffic:

1. Improve the highest-traffic listing first.
2. Create two thumbnail variants for the best product.
3. Create one price/bundle test.
4. Publish five to ten additional Pinterest pins based on the best hook.

If there is no meaningful traffic:

1. Rewrite Etsy titles and tags.
2. Add more long-tail listing variants.
3. Publish more Pinterest pins.
4. Consider a small ad test only after the listing promise is clear.
