# Service Access Checklist

This checklist shows which services the user can sign up for or connect so the
marketing and sales agents can do more autonomous work.

## Access principles

- Use the lowest-cost stack until there is evidence of traffic or sales.
- Prefer tools with exportable data, simple permissions, and clear billing.
- Keep payment, identity, tax, and legal setup as owner-only tasks.
- Give agents access only to the accounts needed for the current test.
- Do not run paid spend without an explicit budget and success threshold.

## Required for launch

| Service | Purpose | Owner action | Agent can do after access |
| --- | --- | --- | --- |
| Etsy seller account | Marketplace sales | Create account, payment, tax, policies | Prepare listings, image text, SEO variants, performance readouts |
| Gumroad | Direct checkout, free sample, email capture | Create account, payout, product shell access | Populate product pages, workflows, free sample, buyer emails |
| Pinterest business | Organic discovery | Create business account | Build boards, schedule/publish pins, monitor pin performance |
| Google Drive | Review and file handoff | Create/share folder | Organize user-facing docs, product files, image prompts, trackers |
| Domain/email | Brand trust | Buy domain and set forwarding | Draft landing page, support macros, email copy |

## AI creative tools

| Tool | Best use | Notes |
| --- | --- | --- |
| ChatGPT Images 2.0 / `gpt-image-2` | Text-heavy listing graphics, infographics, thumbnails, comparison images | Use when accurate text rendering and structured layouts matter. |
| Gemini Image / Nano Banana | Pin variants, image editing, visual concept exploration, consistent design directions | Use for fast creative iteration and conversational edits. |
| Canva | Final marketplace graphics, templates, brand consistency, PDF layout | Useful even when AI generates the first concept. |

Owner action:

1. Decide which AI image tools to use first.
2. Provide API access or shared workspace access if available.
3. Confirm whether generated images should include AI disclosure where required.

Agent-ready outputs after access:

- Etsy thumbnails.
- Secondary listing images.
- Pinterest pins.
- Gumroad covers.
- Simple infographics.
- PDF layout direction.
- Image prompt library.

## Scheduling and distribution

| Tool | Best use | Owner action | Agent can do after access |
| --- | --- | --- | --- |
| Pinterest native scheduler | Lowest-cost first pins | Connect Pinterest | Schedule launch pins manually or in batches |
| Tailwind | Pinterest-first scheduling and testing | Sign up if volume justifies it | Build recurring pin queue and board schedule |
| Buffer or Later | Multi-platform scheduling | Sign up if additional channels are added | Schedule posts across channels |
| Zapier or Make | Lightweight automation | Connect accounts | Sync purchases, leads, and notifications |

## Email and customer lifecycle

| Tool | Best use | Owner action | Agent can do after access |
| --- | --- | --- | --- |
| Gumroad Workflows | Simple buyer and subscriber emails | Enable workflows | Draft and configure welcome, follow-up, and upsell emails |
| MailerLite | Newsletter and lead nurturing | Create account and connect domain | Build segments, automations, landing forms |
| EmailOctopus | Low-cost email list | Create account | Build basic campaigns and subscriber flows |

## Paid acquisition

Do not start here unless listings have a clear offer and baseline conversion
data.

| Channel | Use case | Minimum setup |
| --- | --- | --- |
| Etsy Ads | Test marketplace search demand | Daily cap, target products, baseline listing copy |
| Pinterest Ads | Test visual traffic to Gumroad/Etsy | Pin variants, conversion goal, budget cap |
| Meta Ads | Later retargeting or lead magnet tests | Pixel, landing page, clear audience |
| Google Search Ads | Later high-intent tests | Keyword list, landing page, conversion tracking |

Owner action before spend:

1. Approve budget cap.
2. Approve target channel.
3. Approve offer and claims.
4. Confirm payment method.

## Sales and outbound

Use carefully and ethically. The goal is targeted market learning, not spam.

Possible tools:

- Apollo.io for lead discovery.
- Clay for enrichment and workflow building.
- Instantly, Smartlead, or comparable tools only if cold email becomes a
  deliberate test.
- Google Sheets or Airtable for a low-cost first lead list.

Owner action:

1. Approve outbound as a test.
2. Confirm compliance expectations.
3. Approve sender domain and email setup.
4. Approve daily send limits.

Agent-ready work:

- Build lead criteria.
- Draft outreach copy.
- Draft broker/team lead partnership emails.
- Maintain response tracker.
- Summarize market feedback.

## Analytics and tracking

Minimum tracking stack:

- Etsy stats.
- Gumroad sales and subscriber exports.
- Pinterest analytics.
- Manual tracker in Google Sheets or markdown.

Optional later:

- GA4 on landing page.
- UTM links.
- Looker Studio dashboard.
- Airtable experiment database.

## Suggested setup sequence

1. Google Drive folder.
2. Etsy seller account.
3. Gumroad account.
4. Pinterest business account.
5. Domain and email forwarding.
6. Canva workspace.
7. One AI image tool with export rights.
8. Email tool only if Gumroad Workflows are insufficient.
9. Scheduler only after the first pin batch is ready.
10. Paid ads only after baseline organic data exists.

## Immediate user asks

The fastest path is for the user to create or share:

1. A Google Drive folder for Listinglever.
2. Etsy seller account access or screenshots of listing setup fields.
3. Gumroad account access.
4. Pinterest business account access.
5. Preferred AI image tool access: ChatGPT Images 2.0, Nano Banana/Gemini Image,
   Canva, or all three.
