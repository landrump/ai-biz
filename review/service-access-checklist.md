# Service Access Checklist

This checklist shows which services the user can sign up for or connect so the
marketing and sales agents can do more autonomous work.

## Access principles

- Use the lowest-cost stack until there is evidence of traffic or sales.
- Prefer tools with exportable data, simple permissions, and clear billing.
- Keep payment, identity, tax, and legal setup as owner-only tasks.
- Give agents access only to the accounts needed for the current test.
- Do not run paid spend without an explicit budget and success threshold.

## AI creative tools

| Tool | Best use | Notes |
| --- | --- | --- |
| ChatGPT Images 2.0 / `gpt-image-2` | Text-heavy listing graphics, infographics, thumbnails, comparison images | Use when accurate text rendering and structured layouts matter. |
| Gemini Image / Nano Banana | Pin variants, image editing, visual concept exploration, consistent design directions | Use for fast creative iteration and conversational edits. |
| Canva | Optional fallback for editable layouts and manual export control | Not required for the first launch if ChatGPT Images 2.0 and Nano Banana can produce acceptable assets. |

Owner action:

1. Decide which AI image tools to use first.
2. Provide API access or shared workspace access if available.
3. Confirm whether generated images should include AI disclosure where required.

Agent-ready outputs after access:

- Etsy thumbnails.
- Secondary listing images.
- Pinterest pins.
- Gumroad covers.
- Simple infographics.
- PDF layout direction.
- Image prompt library.

## AI-first creative workflow

The default creative workflow should avoid Canva unless a practical limitation
appears.

1. Use ChatGPT Images 2.0 / `gpt-image-2` for Etsy image sets, product mockups,
   comparison graphics, and Gumroad covers where text accuracy matters.
2. Use Gemini Image / Nano Banana for rapid Pinterest variants, edits, background
   concepts, and alternate visual directions.
3. Export final PNG/JPG/PDF assets directly when quality is sufficient.
4. Use Canva only if the team needs editable templates, manual resizing, brand
   kits, or more reliable final layout control.
5. Track which model created each asset so winning creative styles can be
   repeated.

## Paid acquisition

Do not start here unless listings have a clear offer and baseline conversion
data.

| Channel | Use case | Minimum setup |
| --- | --- | --- |
| Etsy Ads | Test marketplace search demand | Daily cap, target products, baseline listing copy |
| Pinterest Ads | Test visual traffic to Gumroad/Etsy | Pin variants, conversion goal, budget cap |
| Meta Ads | Later retargeting or lead magnet tests | Pixel, landing page, clear audience |
| Google Search Ads | Later high-intent tests | Keyword list, landing page, conversion tracking |

Owner action before spend:

1. Approve budget cap.
2. Approve target channel.
3. Approve offer and claims.
4. Confirm payment method.

## Sales and outbound

Use carefully and ethically. The goal is targeted market learning, not spam.

Possible tools:

- Apollo.io for lead discovery.
- Clay for enrichment and workflow building.
- Instantly, Smartlead, or comparable tools only if cold email becomes a
  deliberate test.
- Google Sheets or Airtable for a low-cost first lead list.

Owner action:

1. Approve outbound as a test.
2. Confirm compliance expectations.
3. Approve sender domain and email setup.
4. Approve daily send limits.

Agent-ready work:

- Build lead criteria.
- Draft outreach copy.
- Draft broker/team lead partnership emails.
- Maintain response tracker.
- Summarize market feedback.

## Analytics and tracking

Minimum tracking stack:

- Etsy stats.
- Gumroad sales and subscriber exports.
- Pinterest analytics.
- Manual tracker in Google Sheets or markdown.

Optional later:

- GA4 on landing page.
- UTM links.
- Looker Studio dashboard.
- Airtable experiment database.

## Suggested setup sequence

1. Confirm Google Drive folder permissions.
2. Finish Etsy shop, payout, policy, and listing setup.
3. Create Gumroad account.
4. Create Pinterest business account.
5. Confirm email forwarding for `listinglever.net`.
6. Provide one AI image tool with export rights.
7. Add the second AI image tool if creative volume or quality requires it.
8. Use Canva only if AI-only exports are not good enough for launch assets.
9. Email tool only if Gumroad Workflows are insufficient.
10. Scheduler only after the first pin batch is ready.
11. Paid ads only after baseline organic data exists.
