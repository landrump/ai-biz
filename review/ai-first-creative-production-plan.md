# AI-First Creative Production Plan

This plan assumes Listinglever creative assets are produced first with AI image
tools such as ChatGPT Images 2.0 / `gpt-image-2` and Gemini Image / Nano Banana.
Canva is optional, not required.

## Position on Canva

Canva is useful for editable templates, brand kits, and fast manual layout fixes,
but it is not required for launch if AI image tools can produce:

- Legible text.
- Consistent visual hierarchy.
- Exportable marketplace image sizes.
- Repeatable brand style.
- Product mockups and PDF cover concepts.

Default stance:

> Use AI image tools first. Add Canva only if final files need manual editability,
> platform-specific resizing, or brand-kit control that AI exports cannot handle
> cleanly.

## Primary creative tools

### ChatGPT Images 2.0 / `gpt-image-2`

Use for:

- Etsy main listing images with readable text.
- Product mockups.
- Comparison graphics.
- Gumroad cover images.
- Simple infographics.
- Visual summaries of workflow steps.

### Gemini Image / Nano Banana

Use for:

- Fast Pinterest pin variants.
- Editing and remixing existing images.
- Visual concept exploration.
- Multiple style directions from one prompt.
- High-volume creative testing.

## Brand style direction

Visual style:

- Clean, modern, business-focused.
- White or warm off-white background.
- Deep navy, muted teal, and soft gold accents.
- Minimal real estate imagery; avoid cheesy house icons when possible.
- Use document mockups, checklist panels, workflow arrows, and polished
  dashboard-like layouts.

Tone:

- Practical.
- Professional.
- Time-saving.
- Clear and non-hype.

Avoid:

- Fake testimonials.
- Fake sales dashboards.
- Fake NAR/brokerage endorsement.
- Overpromising leads, clients, income, or legal compliance.

## Image prompt template

```text
Create a clean, professional digital product marketing graphic for Listinglever,
a faceless brand selling AI workflow kits for real estate agents.

Format: [platform and dimensions]
Product: [product name]
Audience: real estate agents
Primary message: [overlay text]
Supporting detail: [short subtext]

Visual style:
- Modern business document mockup
- White or warm off-white background
- Deep navy, muted teal, and soft gold accents
- Clear text hierarchy
- Mobile-readable text
- No people, no fake testimonials, no fake platform logos

Include:
- A polished PDF/workbook mockup
- Simple workflow/checklist elements
- Subtle real estate context without relying on stock-photo cliches

Avoid:
- Legal compliance claims
- NAR endorsement
- Guaranteed leads or sales
- Tiny unreadable text
```

## Asset review checklist

Before publishing an AI-generated image, confirm:

- Text is spelled correctly.
- Text is readable on mobile.
- Product name matches the listing.
- No fake endorsement, fake testimonial, or misleading claim appears.
- No legal/compliance guarantee appears.
- Image fits platform dimensions.
- Style is consistent with the other Listinglever assets.

## When to add Canva

Add Canva only if:

- AI-generated text is consistently unreliable.
- A human-editable template is needed for repeated resizing.
- The same design must be exported in many sizes.
- Brand colors/fonts need stricter control.
- Marketplace images need small manual adjustments before upload.

Canva should be treated as a production utility, not a core requirement.
