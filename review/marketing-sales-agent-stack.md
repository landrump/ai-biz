# Marketing and Sales Agent Stack

This document defines the marketing and sales agents that should support
Listinglever and future workflow-kit brands.

## Goal

Create a mostly autonomous marketing and sales system where the user handles
account setup, payment approvals, and sensitive approvals, while agents create,
publish, test, and iterate as much as tool access allows.

## Agent map

| Function | Agent | Primary output |
| --- | --- | --- |
| Campaign coordination | Marketing Orchestrator Agent | Weekly marketing plan, campaign calendar, task routing |
| Organic content | Content Engine Agent | Pinterest, blog, email, short-form copy, repurposed content |
| Visual production | Creative Production Agent | Image prompts, creative briefs, thumbnails, pin concepts |
| Marketplace conversion | Marketplace SEO Agent | Etsy/Gumroad titles, tags, descriptions, listing tests |
| Email revenue | Email Lifecycle Agent | Lead magnet sequence, buyer onboarding, upsell emails |
| Paid testing | Paid Acquisition Agent | Small-budget ad tests and performance reads |
| Direct sales | Sales Outreach Agent | Ethical low-touch outreach, broker/team-lead scripts |
| Partnerships | Partnerships Agent | Affiliate, newsletter, broker/community partnership pitches |
| Measurement | Analytics Growth Agent | Dashboards, experiment logs, next-action decisions |

## Operating model

1. The Marketing Orchestrator Agent sets the weekly objective.
2. The Marketplace SEO Agent improves listings and search-driven assets.
3. The Content Engine Agent creates organic traffic assets.
4. The Creative Production Agent creates image prompts and production specs.
5. The Email Lifecycle Agent captures and monetizes subscribers/customers.
6. The Paid Acquisition Agent runs small spend tests only after baseline assets
   are clear.
7. The Sales Outreach Agent and Partnerships Agent test non-manual distribution
   through controlled, ethical outreach.
8. The Analytics Growth Agent reviews metrics and decides the next iteration.

## Tool selection principle

Use the best available tool for the job, not a fixed favorite:

- Use ChatGPT Images 2.0 / `gpt-image-2` when high-quality text rendering,
  product mockups, infographics, or clean marketplace images are needed.
- Use Google Gemini image generation / Nano Banana models when strong image
  editing, fast variants, or grounded visual concepts are useful.
- Use Canva when final layout, brand consistency, export control, and editable
  templates matter.
- Use scheduling tools such as Tailwind, Buffer, Later, or Pinterest native
  scheduling when account access exists.
- Use Gumroad Workflows, MailerLite, EmailOctopus, or similar email systems for
  lead capture and lifecycle messages.
- Use Zapier or Make only when automation saves recurring work after a manual
  process is proven.

## Guardrails

- Do not buy ads, subscribe to tools, or publish externally without user-approved
  account access and budget.
- Do not use spam, scraped personal data, fake urgency, fake testimonials, or
  misleading income claims.
- Do not claim legal, NAR, brokerage, MLS, or state compliance.
- Keep every campaign tied to one measurable objective.
- Treat creative output as testable assets, not proof of demand.

## First marketing system for Listinglever

The first system should focus on:

1. Etsy listing conversion.
2. Pinterest pin volume and testing.
3. Gumroad free checklist and bundle conversion.
4. Email capture and nurture.
5. Low-touch outreach to brokers, team leads, and real estate assistants only
   after the public assets are credible.

## First metrics

- Etsy impressions.
- Etsy listing click-through rate.
- Favorites and carts.
- Sales and refund rate.
- Gumroad page views.
- Free checklist downloads.
- Email open and click rates.
- Pinterest impressions, saves, outbound clicks.
- Outreach reply rate.
- Partnership response rate.

## Owner approvals required

- Tool subscriptions.
- Ad spend.
- Public account creation.
- Email sending domain setup.
- Any external publishing.
- Any outbound list source that uses personal data.
- Final approval of compliance-sensitive claims.
