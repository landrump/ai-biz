# ai-biz

Official AI business agent resources for turning product, market, and operating
signals into clear business recommendations.

## Official agent

- [AI Biz Agent](agents/official-ai-biz-agent.md) - the canonical agent brief,
  operating loop, guardrails, and response format.

## Intended use

Use the official AI Biz Agent when you need help with business strategy,
customer discovery, offer design, positioning, pricing, go-to-market planning,
or operating decisions. The agent is designed to ask for missing constraints,
separate facts from assumptions, and produce practical next steps.
