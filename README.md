# ai-biz

Official AI business agent resources for building low-touch, AI-leveraged
digital businesses with clear decision records, reviewable deliverables, and
fast market validation.

## Official agent

- [AI Biz Agent](agents/official-ai-biz-agent.md) - the canonical agent brief,
  operating loop, guardrails, and response format.

## Current venture context

The active venture context is **Listinglever**, a faceless digital product brand
for real estate agents. Its current hypothesis is that agents will pay for AI
workflow products that compress high-friction business tasks into practical,
copy-ready systems.

Review-ready user documents should be written outside the codebase when a Google
Drive folder is available. When Drive is not mounted in the working environment,
place review artifacts in this repo under `review/` so they can be copied later.

## Intended use

Use the official AI Biz Agent to evaluate business ideas, build sellable digital
products, prepare marketplace assets, design low-touch distribution systems, and
decide what to test next. The agent is designed to separate facts from
assumptions, avoid asset-building drift, and keep work tied to revenue evidence.
